# 다면체 데이터 만들기 (polydata.py)

프로그램에는 필요 없고, `polydata.py` 를 다시 만들 때만 씁니다. (scipy, shapely 필요)

1. `snub.py` — 다듬은 정십이면체 꼭짓점을 수치로 찾기 (snub_dodeca.npy)
2. `gen.py` — 정다면체·아르키메데스 다면체 좌표 → 볼록 껍질 → 면, 쌍대로 카탈랑 다면체, 바닥 면 정렬·크기 맞추기
3. `nets.py` — 가장 가파른 모서리 자르기(steepest-edge)로 펼치는 순서를 여러 번 시도해 겹치지 않는 전개도 고르기

※ 스크립트 안의 파일 경로는 만들 때 쓰던 임시 폴더입니다. 다시 쓸 때 고쳐 주세요.
