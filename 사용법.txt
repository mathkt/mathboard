도형그리기
==========

[받기 - 가장 쉬운 방법]
GitHub 저장소의 Releases(배포) 페이지에서 exe 파일 하나만 받아 실행합니다.
(설치·파이썬 필요 없음. 새 버전이 나오면 새 exe로 바꾸기만 하면 됩니다)

[직접 만들기 (파이썬이 있을 때)]
1. python.org 에서 Python 설치 ("Add python.exe to PATH" 체크)
2. 이 폴더의 "exe만들기.bat" 더블클릭 → "도형그리기.exe" 생성
3. 이후엔 도형그리기.exe 만 실행 (다른 PC에는 exe 하나만 복사)

※ exe 없이 바로 써 보려면 "바로실행(파이썬).bat" (부품 설치 후)

[파일 구성]
main.py    메인 창·메뉴·내보내기
canvas.py  그림판(마우스 조작)
render.py  그리기(중괄호, 각 화살표 등)
panel.py   오른쪽 속성 창
model.py   데이터·계산
solid.py   입체도형 (모양·숨은 선·겉넓이·부피)
fonts/     CMU Serif 글꼴
작업 파일 확장자: .dhg

[1.8.1 바뀐 점]
· 쌓기: 층마다 반지름·높이를 한 줄에 하나씩 넓은 칸으로 (cm 단위 표시)

[1.8 바뀐 점]
· 단축키: 선택 S, 선분 V (서로 바꿈)
· 면 위 점: 점 도구로 입체의 면 클릭 → 그 면에 붙은 점 (끌면 면 안에서 움직임)
· 원 둘레 위 점: 원기둥·원뿔 등의 밑면·윗면 원을 클릭 → 끌면 원을 따라 돎
· 입체 위에 그린 다각형도 안쪽을 클릭하면 선택됨, Alt+클릭으로 그 다각형만 색칠
· 선분·직선·반직선: Shift 누르고 그리면 수평·수직·30°·45°·60°
· 왼쪽 도구 창: '작도' 제목을 눌러 접기/펴기
· 쌓기 층의 반지름·높이 칸을 넓혀 숫자를 직접 입력하기 쉽게
· 프로그램 아이콘

[1.7 바뀐 점]
· 왼쪽 도구 창·오른쪽 속성 창: 경계선을 끌어 폭 조절(도구는 줄 수 자동), F3·F4로 숨기기/보이기
· 입체도형(K): 누르면 바로 창 → 확인 후 마우스를 따라 겨냥도 미리보기 → 클릭해서 놓기
· 놓는 방향(눕히기): 밑면이 위·오른쪽·왼쪽·앞·뒤를 향하게, 슬라이더로 기울이기
· 쌓기: 층마다 원기둥·원뿔·거꾸로 원뿔·원뿔대·반구 선택, 층 순서 바꾸기, 크기 칸 글씨 정리
· 선마다 실선·점선: 속성 창 '선 고르기' → 선 클릭 → 자동/실선/점선/숨김, 굵기·색
· 겹치기 '안쪽 선': 자동 / 모두 실선 / 모두 점선 / 숨김
· 그룹: Ctrl+G 묶기, Ctrl+Shift+G 풀기, 더블클릭으로 그룹 안 하나만 고르기
· 단축키 바뀜: 모눈 보이기 F9, 모눈에 맞추기 Shift+F9 (Ctrl+G 는 그룹)

[1.6 바뀐 점]
· 접선(W), 길이가 같은 선분 옮기기(E), 크기가 같은 각 옮기기(F) - 컴퍼스 흔적 포함
· 작도 메뉴 → 삼각형 작도 (SSS·SAS·ASA): 흔적·길이·각 표시와 함께
· 삼각형을 선택하면 속성 창에 외심·내심·무게중심·수심 (외접원·내접원·중선·수선)
· 전개도: 입체도형 선택 → 속성 창 '전개도'. 펼치는 모양 선택, 접기 슬라이더로 접어 보기
  (원기둥·원뿔·원뿔대도 전개도, 구와 쌓기는 제외)

[1.5 바뀐 점]
· 위 도구모음 단축키 글자 없앰(마우스를 올리면 보임), 속성 창 정리(한 줄 배치·접기·색 팝업)
· 작도: 중점(D), 수직이등분선(H), 각의 이등분선(J), 수선(U), 평행선(Y), 교점(I) - 원래 점을 움직이면 따라감
· 작도 흔적(컴퍼스 호) 자동 표시 (설정에서 켜고 끔)
· 수선: 수선의 발 + 직각 표시. 입체 위 점에서 모서리·면으로도 (예: 각뿔 꼭짓점 → 밑면 = 높이, 실제 3D 길이)
· 점 도구로 선·원 위 클릭: 그 위를 움직이는 점 / 교점
· 컴퍼스(O): 너비 입력 또는 두 점으로 재기 → 고정점 클릭 → 끌어 돌린 만큼 호

[1.4 바뀐 점]
· 입체 점 잡기: 꼭짓점·모서리 위를 점처럼 클릭 → 선분·길이·각 (돌려도 따라가고 실제 3D 길이·각)
· 원의 중심점 보이기/숨기기
· 면 색칠: Alt+클릭 (뒤쪽 면은 Alt+Shift+클릭)
· 자르기: 점 3개 또는 방향(기울기·방향·위치), 단면 이름·넓이, 벌리기, 한쪽 조각만
· 겹치기: 다른 입체 안에 넣기 (안쪽 선 실선/점선), 쌓기(회전체: 연필·팽이·캡슐 등)

[1.3 바뀐 점]
· 기본 글꼴 CMU Serif, 미지수(x, y, a, θ)는 TeX 수식용 기울임체로 자동
· 길이 표시 기본: 호 + 파선 (직접 입력 칸에 쓰면 바로 직접 입력으로)
· 그린 뒤 자동으로 [선택] 도구 (Shift 누르고 그리면 도구 유지)
· 탭: 그림판 위 1번·2번 탭, ＋ 또는 Ctrl+T 로 추가, 더블클릭 이름 바꾸기, 오른쪽 클릭 복제·지우기, 한 파일에 모두 저장
· 호·부채꼴 도구(Q)
· 각 화살표 직선/곡선, 화살표 크기
· 그림 복사·PNG: 선택한 것만 (선택 없으면 전체), PNG 형식으로 복사
· 속성 창: 휠로 내려도 값이 안 바뀜(칸을 클릭한 뒤에만), 칸 너비 줄임
· 이름 끌기 거리 제한

[1.2 바뀐 점]
· 입체도형(K): 정육면체~구 9종, 겨냥도·회전(더블클릭), 숨은 선 자동 점선, 꼭짓점 이름, 모서리 길이 표시, 겉넓이·부피
· 교과서 스타일: 설정 → 환경 설정 → '교과서 스타일로 맞추기' (CMU Serif, x·θ 기울임, ° 작은 동그라미)
· fonts 폴더: CMU Serif 글꼴 (무료 OFL 라이선스, exe에 함께 들어감)

[1.1 바뀐 점]
· 길이 표시: 중괄호 / 호 선택 (속성 창). 호는 가운데에 글자, 글자 없음이면 그냥 호
· 설정 → 환경 설정 → 단축키 탭에서 단축키 변경
· 왼쪽 도구 버튼에 단축키 표시

[주요 사용법]  → 프로그램 안에서 F1
· 그림 복사(Ctrl+Shift+C) 후 한글/PPT에 Ctrl+V
· 1칸 모눈 = 1cm (붙여넣으면 거의 실제 크기)
